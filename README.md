# Portafolio Personal

Sitio web de portafolio personal construido con HTML5, CSS3 y JavaScript vanilla.

## Características

- Diseño responsive (mobile-first)
- Secciones: Inicio, Sobre mí, Habilidades, Proyectos y Contacto
- Animaciones suaves al hacer scroll
- Barras de progreso animadas para habilidades
- Formulario de contacto con validación
- Navbar fija con menú hamburguesa en móvil

## Estructura

```
portafolio/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
└── README.md
```

## Uso

Abre `index.html` directamente en tu navegador o despliégalo en cualquier servicio de hosting estático (GitHub Pages, Netlify, Vercel, etc.).
